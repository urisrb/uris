The mark is four slashes — the character a URI is built out of, and the one a feed lives
behind in `uris.to/buy`. Round the right corners and the same four strokes spell the name:
the first closes across the bottom into a u, the second rounds its top left into an r, the
third is left alone as the i, and the fourth rounds top left and bottom right into an s.
It is drawn in kind colours, so it is the product's own palette rather than a logo
standing beside it.

## It holds up small

The mark has to work at 16px in a browser tab and at 200px on a page. Four strokes is the
most it can carry and still read as slashes rather than a smear.

## Ends and corners

A round cap overshoots the endpoint by half the stroke, and because the strokes are
slanted that overshoot lands slightly left of where the eye expects the edge. Flat ends
put every top and bottom on the same two lines exactly, so that is the one in use.

What rounds is never the cap, then, but a corner. Every stroke is the same slanted bar —
its four corners sit 1.5 either side of the endpoints, square to the slant — and the
letters differ only in which of those corners an arc replaces. The radius is 1.5, exactly
half the stroke, so each arc is tangent to the endpoint the bare slash already had and the
four still sit on one grid. On the u both bottom corners round, and at that radius they
meet with nothing between them and close into a single semicircle.

## Lockup

The mark carries the colour, so the wordmark beside it stays plain. Never set the word in
colour as well.

## The palette

Thirteen kinds, each with a colour. The mark takes four of them; the catalog tints every
item by its own.

link, a focus ring, the glow behind the sign-in. It is never a kind.

## Ground

| Token | | |
| --- | --- | --- |
| `--void` | `#080d0f` | the page |
| `--base` | `#0d1417` | the working surface |
| `--raised` | `#131f23` | a panel on it |
| `--lifted` | `#1a282d` | the current row |
| `--line` | `#1e2d33` | a hairline |
| `--text` | `#d9e8eb` | body |
| `--bright` | `#f3fbfc` | headings |

Type is the system stack with `Helvetica Neue` in it, and IBM Plex Mono for anything a
machine wrote — an id, a locator, a tool name. No display face: the spacing, the grid and
these eleven colours do the work.
