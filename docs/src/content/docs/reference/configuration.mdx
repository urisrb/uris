Nothing in the repository names a host, a domain, or a secret. Everything arrives through the
environment; `.env.example` documents the full set and `bin/setup` copies it to `.env`.

## Application

| | Default | |
| --- | --- | --- |
| `URIS_HOST_SUFFIX` | `uris.test` | the suffix tenant subdomains hang off; read in `config/environments/development.rb` |
| `PORT` | 4242 | |
| `URIS_PUBLIC_ORIGIN` | — | overrides `request.base_url` in `Tenant.origin`, and takes `%{subdomain}` the way `MASKS_ISSUER_TEMPLATE` does. Must be stable, since OAuth redirect URIs register against it. Blank when not tunnelling |

## Datastores

| | Default | |
| --- | --- | --- |
| `POSTGRES_HOST` `POSTGRES_PORT` | `127.0.0.1`, 5434 | |
| `POSTGRES_USER` `POSTGRES_PASSWORD` | `uris` | must not be a superuser |
| `OPENSEARCH_URL` | `http://127.0.0.1:9201` | read in `SearchIndex.client` |
| `PG_BIN_PATH` | — | prepended to `PATH` in `config/application.rb`, for when the linked `pg_dump` is older than the server in `compose.yml` |

:::caution[The application role must not be a superuser]
A superuser bypasses row-level security unconditionally, and a table's owner bypasses it unless the
table is `FORCE`d. Either makes every isolation test pass without proving anything.
`db/docker-entrypoint-initdb.d` creates a separate non-superuser role, and CI does the same. See
[Tenancy](/concepts/tenancy/).
:::

Solid Queue runs in a second database (`config.solid_queue.connects_to`), in development as well as
production.

## Storage

| | Default | |
| --- | --- | --- |
| `S3_ENDPOINT` `S3_REGION` | `http://127.0.0.1:9000`, `us-east-1` | read by `db/seeds.rb` only |
| `S3_ACCESS_KEY_ID` `S3_SECRET_ACCESS_KEY` | `uris` / `urisuris` | read by `db/seeds.rb` only |
| `URIS_FILESYSTEM_ROOTS` | *unset* | colon-separated roots a `filesystem` resource may be rooted under |

An `s3` resource carries its own endpoint and credentials in its row. The `S3_*` variables only seed
the development MinIO bucket.

| `URIS_GIT_ROOT` | *unset* | where a `git` resource keeps its shallow bare clones |
| `URIS_GIT_PROTOCOLS` | `https` | which transports git may dial, comma-separated |

`URIS_FILESYSTEM_ROOTS` unset makes the `filesystem` type unusable, which is the intended default
for a server holding more than one tenant's catalog. `Resource::Filesystem::Escaped` is raised on a
path that leaves its root. `URIS_GIT_ROOT` is unset by the same reasoning: a server holding many
tenants does not write clones wherever it likes.

`URIS_GIT_PROTOCOLS` is both the validation the model applies to a URL and the `GIT_ALLOW_PROTOCOL`
the subprocess is given. It defaults to https alone because `git://` and `file://` reach things that
are not repositories and `ext::` runs a command.

## Reaching out

| | Default | |
| --- | --- | --- |
| `URIS_INFERENCE_ORIGINS` | *unset* | comma-separated origins an `openai-compatible` resource may dial |
| `URIS_SEARCH_ORIGINS` | *unset* | the same, for a self-hosted `search` resource |
| `URIS_CHROME_PATH` | *unset* | where the headless browser lives; unset means the usual places for the platform |
| `URIS_CHROME_NO_SANDBOX` | *unset* | any value drops Chrome's own sandbox |

An origin allowlist rather than a URL one: the resource row carries the address, the environment
decides which addresses this deployment will dial at all. Unset means the type is unusable, which is
the right default — `Resource::OpenaiCompatible#permitted!` says so by name.

:::caution[The sandbox is the last guard]
`URIS_CHROME_NO_SANDBOX` is for a container that cannot give Chrome the namespaces it needs. Prefer
`--cap-add=SYS_ADMIN` or a seccomp profile allowing `clone`. See [Snapshots](/concepts/items/).
:::

## Analysis

| | Default | |
| --- | --- | --- |
| `URIS_EMBEDDING_DIMENSIONS` | 768 | how wide a vector the search index holds |
| `URIS_WHISPER_MODEL` | *unset* | a ggml model file for whisper.cpp |
| `URIS_WHISPER_BIN` | `whisper-cli` | the binary to run it with |
| `URIS_TRANSCRIBE_SECONDS` | 3600 | how much of a long recording is decoded |

`URIS_EMBEDDING_DIMENSIONS` is part of the index mapping, so changing it changes the stamp and the
index rebuilds itself; `check_resource` refuses an embedding model whose vectors are a different
width. See [Search](/guides/search/).

`URIS_WHISPER_MODEL` unset means recordings are catalogued from their metadata and nothing is
transcribed, which the transcript step records as its own error rather than leaving the item looking
analyzed. Models are downloaded rather than packaged. See [Analysis](/concepts/analysis/).

## Encryption

| |
| --- |
| `ENCRYPTION_PRIMARY_KEY` |
| `ENCRYPTION_DETERMINISTIC_KEY` |
| `ENCRYPTION_KEY_DERIVATION_SALT` |

Read in `config/application.rb` into `config.active_record.encryption`. `Resource#credentials` and
`Tenant#client_secret` are encrypted with them.

The values in `.env.example` are development-only and named so. Generate real ones with:

```sh
bin/rails db:encryption:init
```

## Auth

| | |
| --- | --- |
| `MASKS_ISSUER_TEMPLATE` | the tenant's issuer, as a template over `%{subdomain}` |

Read in `Tenant.issuer_url`, which raises `Tenant::Unconfigured` when it is unset. Tokens are
rejected unless `iss` matches it and `aud` matches the tenant's own `/mcp` URL. There is no local
minting path.

## Limits

Read in `config/application.rb` into `config.uris`:

| | Default | Applies to |
| --- | --- | --- |
| `URIS_MCP_LIMIT` | 120 / minute | every `/mcp` call |
| `URIS_RUN_BUDGET` | 20 / hour | tools declaring `starts_runs`; `0` disables |
| `URIS_AUDIT_RETENTION_DAYS` | 90 | `SweepAuditEventsJob` |
| `URIS_RUN_RETENTION_DAYS` | 14 | `SweepRunsJob` |
| `URIS_RUN_DEADLINE_HOURS` | 6 | how long a run may stay open before it is cancelled |

## Switches

| | |
| --- | --- |
| `URIS_ITERATORS_DISABLED` | any value stops every iteration job everywhere |

An operator switch, read by `Gate.stopped_everywhere?`. Per-tenant and per-resource switches are
`gates` rows — see [Jobs](/concepts/jobs/).
