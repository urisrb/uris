Yours, together. A Rails application that catalogues your storage accounts, mailboxes, calendars,
repositories and the places you write things down, analyzes what it finds, indexes it in OpenSearch
by word and by meaning, and serves the result over MCP and GraphQL.

<CardGrid stagger>
  <Card title="An item is a reference" icon="seti:db">
    One `items` row, plus a `item_references` row per place the bytes live. Originals are never
    copied into the catalog.
  </Card>
  <Card title="Types are STI subclasses" icon="puzzle">
    `Resource::S3`, `Resource::Imap`, `Resource::Github` and fifteen more, each owning its adapter,
    command schema, locator shape and page enumerator.
  </Card>
  <Card title="The grant builds the tool list" icon="seti:config">
    `POST /mcp`, twelve tools, nine scopes. `Grant#tools` filters `Tool.all` per request, so a tool
    outside the token's scopes is absent from `tools/list`.
  </Card>
  <Card title="Bulk work resumes" icon="approve-check">
    Sync, export, analyze, reindex and dedupe run through
    [job-iteration](https://github.com/Shopify/job-iteration) and checkpoint at a cursor.
  </Card>
</CardGrid>
