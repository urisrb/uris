Drive search only searches Drive. Gmail search only searches Gmail. things searches across all of
them, with analysis attached, and can hand the bytes back as an export or a local copy.

<CardGrid stagger>
  <Card title="The catalog is the product" icon="seti:db">
    A thing is a **reference, not the bytes**. Originals stay in the resource they came from; things
    holds the reference, the extracted metadata, and the analysis.
  </Card>
  <Card title="One adapter, every vendor" icon="puzzle">
    A **type** is a dialect, and it decides how much code exists. One `s3` adapter serves AWS, R2,
    B2, Wasabi, MinIO and Garage — because they all speak the same one.
  </Card>
  <Card title="The endpoint is the interface" icon="seti:config">
    `POST /mcp` — eight tools, one bearer token per call. **The token decides which tools exist**, so
    a tool outside your grant is absent rather than refused.
  </Card>
  <Card title="It survives a deploy" icon="approve-check">
    Every operation touching an unbounded number of things checkpoints through job-iteration, so a
    sync or an export **resumes at its cursor** rather than starting over.
  </Card>
</CardGrid>
