---
title: uris
description: One searchable index across everything you own, wherever it lives, with a way back out.
---

uris catalogs what you already have. It points at the places your things live — buckets,
directories, mailboxes, calendars, feeds, wikis — reads each one, and gives you a single index
over all of them that you can search, ask questions of, and export back out.

Two interfaces reach the same catalog: a browser app over GraphQL, and an MCP endpoint a model
can drive. Both authorize the same way, and neither wraps the other.

:::caution[These docs are being rewritten]
The schema underneath uris was rewritten in September 2026 — one record for a thing, one record
for a pass over it — and every page written against the old shape was removed rather than
patched. `README.md` and `PLAN.md` in the repository are accurate; this site is not, yet.
:::
